# Sindirim Sistemi – 7. Sınıf Fen Bilimleri

Akıllı tahtada ve tarayıcıda kullanılabilen iki etkileşimli ders uygulaması:

- **index.html – Besinin Yolculuğu:** Bir besin seçilir, organlara dokunarak lokma ağızdan anüse götürülür; fiziksel ve kimyasal sindirim sayaçları dolar.
- **ders.html – Ders anlatımı:** Tıklanabilir organlar, lokmanın yolculuğu, besinlerin sindirim tablosu, mekanik/kimyasal sınıflandırma oyunu, test ve sağlık bölümü.

Kurulum gerektirmez; dosyaları tarayıcıda açmak yeterlidir.
